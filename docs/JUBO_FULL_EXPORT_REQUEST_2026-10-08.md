# 向 JUBO 索取正式七年全量匯出：萬華日照

用途：核對並移轉「樂齡歲悅股份有限公司附設臺北市私立歲悅萬華社區長照機構」的既有日照資料。這份清單是向原廠確認可提供資料與格式的請求，不是授權自動登入、爬取或直接匯入正式資料庫。

## 請求範圍

請以原生結構化格式（CSV／XLSX／資料庫匯出擇一，附 UTF-8 編碼及欄位字典）提供最近七年及切換前增量：

1. 個案主檔與完整生命週期：原系統不可變個案 ID、分支 ID、收案／暫停／恢復／轉出／結案日期、聯絡關係、資格及核定計畫版本。
2. 每筆服務與照顧明細：不可變原始紀錄 ID、個案 ID、服務日期與時間、項目／代碼、時數或次數、執行人 ID、狀態、取消與更正來源、簽署及複核紀錄。
3. 出勤、接送、用藥、生命徵象、照顧日誌、量表、異常事件、會議、申訴、帳務與申報：分別列出原始紀錄 ID、版本／前版 ID、發生時間、建立／修改時間、作者、簽署人、作廢狀態和資料來源。用藥與胰島素需有有效醫囑／計畫的關聯 ID。
4. 所有附件清單及原檔：附件 ID、所屬紀錄 ID、檔名、類型、大小、SHA-256、建立時間、版本與原檔；包括身分證、藥袋、用藥計畫、給藥紀錄、體檢與檢驗文件。不得只提供畫面網址或縮圖。
5. 官方申報與回覆：每批次 ID、年度／縣市格式版本、逐筆來源 ID、送出檔、回覆檔、接受／退件／更正狀態及金額，並附欄位代碼／費率版本。
6. 權限與稽核：員工及角色歷史、資料變更和查閱／匯出的可用稽核紀錄；若不能提供，請逐項說明缺失與保留年限。

## 交付與驗收

- 每個資料集附筆數、最早與最新日期、欄位說明、空值語義、時間區域、代碼表及 SHA-256；附件另提供逐檔雜湊清單。避免只交 PDF 報表或不含 ID 的畫面匯出。
- 先交去識別化樣本和欄位字典供映射；正式檔以公司核准的加密傳輸與分離密碼管道交付，不以一般電子郵件寄送明文個資。匯出範圍、執行者、時間、交付對象和雜湊都需留下交接紀錄。
- 至少做兩次完整試轉與一次凍結期間增量。新系統逐資料集、個案、日期、附件與申報金額全量對帳；重大差異為 0，其他差異逐筆核准後才切換。
