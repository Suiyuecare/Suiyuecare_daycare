# API 邊界

所有回應使用 `{ requestId, status, data, errors }`，且包含 `private, no-store`。寫入必須提供冪等鍵；錯誤不回傳 stack、token、原始附件或明文個資。瀏覽器呼叫統一經有界逾時；未知寫入結果保留相同冪等鍵，只有使用者修改內容後才換鍵。一般互動為 20 秒，25MB HTML 上傳／重解析為 60 秒，登出清理為 10 秒。
