## 可放行條件（須逐項留下證據）

1. 機構申報負責人提供實際 115 年臺北服務費用申報檔、至少一份已受理的匿名範本、完整回覆檔及特約約定；記錄來源 URL／檔案雜湊、發布機關、取得日、生效日及核准人。不得只憑檔名或手填 `format_version`。
2. 法遵／財務核對碼別、費率、部分負擔、核定範圍、資格、期限與版本；雙人簽核後才開啟對應年度／縣市格式。測試合法、不合法、跨版本、重送及撤銷場景。
3. 以匿名官方樣本做逐欄往返測試；與已受理結果逐筆比對筆數、代碼、日期、次數、總額及回覆狀態，差異 0。先通過完整平行申報週期，不以程式產出 JSON 或 PDF 代替主管機關受理。
4. 官方回覆須有檔案來源、雜湊、匯入者、時間、格式版本、逐筆對應和不可變原檔；人工 JSON 僅能維持「未驗證來源」狀態，不得作為已核付證據。
5. 品質月報先由主管確認每個指標的年度版本與分子／分母／排除條件，採單一帶版本資料快照；零分母、缺測、不適用、事件更正與跨月回補分開呈現。畫面、下鑽、匯出逐值一致，並以 30 位以上跨月份個案抽驗。

本次程式沒有新增正式申報檔案或品質月報，也沒有連線、寫入或部署正式 Supabase 資料。
