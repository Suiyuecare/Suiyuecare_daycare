# 七類臨床頁「暫時無法載入」診斷紀錄

2026-10-08 對正式首爾 Supabase 與 Vercel 做唯讀核對，範圍是用藥、個案 TOCC、身體評估、行為情緒、ABCD、胰島素與檢查報告的快照讀取。七個 public RPC 及其 private 被呼叫函式均存在；函式參數與現行 `main` 呼叫相符；`authenticated` 可執行，`anon` 不可；2026-10-03 的 Google AAL1 指派個案讀取修正已在正式庫。檢查報告按設計仍需 AAL2。正式 Vercel 最近兩小時沒有可對應的 `routeKey` 診斷事件，Supabase 近 24 小時的 PostgreSQL 日誌沒有相關 SQL ERROR。

這些查核**不能證明頁面對真人正常**，也不能從舊截圖倒推出故障根因。沒有一筆真實失敗的查詢編號，無法分辨是帳號權限、函式執行、資料轉換、環境設定或當時短暫網路問題。不得把 403 當成空清單、提高所有人的權限，或用其他分支資料填充畫面。

下次出現錯誤時，請記錄頁面名稱、畫面顯示的查詢編號（request ID）及台北時間，不需個案姓名、量測值或附件。值班工程人員以查詢編號核對去敏感 Vercel 事件，再按失敗層級重現、修正與回歸；修復後需由原權限角色在正式站實際重試，且跨分支／未指派個案仍被拒絕。沒有這筆證據前，狀態維持「原因未確認」。
