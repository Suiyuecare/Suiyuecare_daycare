- 11 模組、89 頁的**編號、slug、頁名、模組歸屬與頁面驗收條文**只取自 src/lib/catalog/；本文件不以畫面、既有文件或原系統補造頁面。
- 「現有證據」可引用目前程式與測試以判斷成熟度；它不會反向改寫 catalog，也不等於逐頁驗收通過。

- 本文件只使用頁面規格與去識別化／合成案例描述，不含三份中央 HTML 的姓名、識別碼、聯絡資訊、健康內容或附件。

## 2. 成熟度定義

| 成熟度 | 判定 |
|---|---|
| route-only | 只有可到達路由與標題，沒有可操作的業務工作區。 |
| shared workspace | 進入共用工作框架；正式模式為唯讀或空狀態，尚無該頁專用流程。即使已有共用資料表、API 或計算引擎，也維持此標記，直到頁面接上專用能力。 |
| partial | 已有該頁專用元件或資料投影，可執行一部分真實流程，但尚未滿足 catalog 驗收與完整寫入／簽署／匯出／外部證據。 |
| dedicated | 已有頁面專用 UI、API 與測試路徑；仍有正式 adapter、交易、外部或業務簽核門檻，因此尚非完成。 |
| verified | 專用正反向 E2E、RLS／DB 斷言、同快照、安全、無障礙、效能及必要外部驗收均具名簽核。 |

目前分布：route-only=0、shared workspace=10、partial=8、dedicated=71、verified=0，合計 **89** 頁。
