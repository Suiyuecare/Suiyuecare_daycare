## 正式就緒改進（2026-09-26，本輪尚未發布）

- **量表作業：** 新增獨立評估、指定草稿修訂、分頁評估清單與不可變版本歷程；保護未保存輸入，保存結果不明時固定原內容與冪等鍵重試，保存後讀回失敗不假裝未保存。讀取回應嚴格檢查個案、量表及版本範圍。
- **Google 登入：** 已核准員工可用 Google 工作階段讀取／保存未簽署量表草稿，不另要求驗證器。資料庫仍重新檢查機構、分支、個案指派、表單權限、帳號開通與有效工作階段；此改動不解除用藥、申報或正式簽署的 AAL2 條件。
- **寫入安全：** 冪等操作與修訂鏈加上交易級鎖；鎖等待與寫入完成後再次檢查授權。舊核心函式不可由 API 角色直接呼叫，公開入口重新綁定新防護函式。
- **申報回執：** 匯出與對帳 API 核對批次、合法狀態、筆數及金額；對帳接受／拒絕數量必須與輸入項目相符，畸形或不一致回執返回錯誤。匯出的格式版本及快照雜湊僅檢查回執格式，不表示已驗證官方申報檔內容。現有 RPC 沒有提供持久化資料範圍／請求雜湊回執，這個缺口尚未補齊；快照 metadata 也不是官方申報檔。六個相關測試檔共 222 項通過。
- **原生資料庫：** 現有 PostgreSQL 17.11 的八套本機隔離測試在最新 133 份 migration 下全部通過；包含 104→133 的升級，既有合成個案、量測、表單及角色不變。量表另通過 26 項草稿、29 項歷程及 40 項機構開通／JSON 反向測試。此原生測試不替換正式登入判斷，不接觸 hosted DB。
- **真實同時操作：** 50 個獨立 PostgreSQL 連線、同一授權人員、相同操作鍵產生一筆寫入及 49 次精確重播；不同操作鍵競爭修訂同一基準版只有一筆提交，另一筆回報版本衝突。機構在等待期間撤銷，以及請求前已撤銷工作階段，均拒絕操作且沒有額外版本、回執或稽核；本套尚未單獨測試工作階段在等待期間撤銷。這不等於 50 位員工的 HTTP 效能測試。
- **實際本機還原：** 合成測試資料 `pg_dump` 至獨立備份，再還原至第二個資料庫；答案、操作回執與寫入稽核的完整指紋相同，RLS／權限／不可變觸發器保存，還原後撤銷工作階段 RPC 與改寫歷史仍被拒絕。本次約 1.5 秒；不是 hosted PITR、正式資料或七年資料量的 RPO／RTO 驗收。

- **獨立審查追加修正：** 不合法 JSON 直接 RPC 寫入與員工開通的機構綁定漏洞已修正並通過上述 40 項反向／相容性測試；量表 API／預覽／契約／編輯器／真 AppShell＋BranchSwitcher 的七檔 114 項測試通過。包含未保存切側欄／返回／個案／分支／刷新、未知 503 固定重試，以及頂部與左側兩個安全登出出口取消／確認後的操作鎖處理。沒有將答案或操作鍵保存至 localStorage、sessionStorage 或瀏覽器 history。正式資料庫只讀彙總：題目式量表版本目前 0 筆，無需改寫既有個案答案；發布前仍須重檢。新的 `IS TRUE NOT VALID` 約束會保護未來寫入，但不會掃描或修正歷史資料；部署驗收須確認既有版本合法後執行 `VALIDATE CONSTRAINT`。另用合成資料驗證升級前一筆合法及一筆歷史 NULL 狀態草稿，在 migration 前後完整資料雜湊不變，新的同類錯誤被拒絕；不是將歷史錯誤洗成合法。

## 可重跑的原生安全驗收

先提供本機 PostgreSQL 17 的絕對 `bin` 路徑，再執行：

```sh
INTAKE_NATIVE_PG_BIN=/absolute/path/to/postgresql/17/bin pnpm test:database:native
```

八套必須全部通過；任何套件失敗會以非零結束。每套自行建立合成資料的暫存 Unix socket cluster，不接受正式資料庫 URL；結束會停止 cluster，保留暫存稽核／備份產物供檢查。不得替換成正式 `DATABASE_URL` 或將這個還原腳本指向正式 Supabase。
