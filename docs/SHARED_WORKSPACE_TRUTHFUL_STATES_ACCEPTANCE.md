# 共用工作頁：統計與未開放狀態修正

日期：2026-09-11。範圍限 `OperationalWorkspace`；本次不宣稱補齊各頁專用業務功能，也未發佈。

## 問題與處理

| 場景 | 修正前 | 修正後 |
| --- | --- | --- |
| 正式模式，尚未提供資料來源 | 空陣列被表示為 0 筆，同時出現固定 1／2／3 等摘要與「今天 10:24」 | 不顯示統計卡、業務筆數或資料更新時間；清楚說明本頁未開放，不能據此判斷待辦或完成情況 |
| 正式模式空清單 | 建議清除篩選或新增，但新增按鈕實際停用 | 不呈現無效搜尋與清除篩選；提示先使用機構現行紀錄流程，必要時聯絡主管 |
| 展示模式 | 任意業務指標名稱搭配固定數字 | 顯眼標示合成展示，僅依展示清單計算總筆數及各狀態數；摘要分母明示為全部展示紀錄，不隨搜尋變動 |
| 無操作的控制項 | 匯出與更多篩選看似可用，但沒有實作 | 匯出明示未開放並停用；移除無功能的更多篩選按鈕 |
| 展示草稿 | 提示伺服器時間會於送出寫入，但實際只在瀏覽器保存 | 明示只保留於目前頁面，不寫入正式紀錄，重新整理後復原 |
| 工程／驗收說明 | 直接放在工作規則與「本頁可用篩選」 | 改為預設收合的管理參考，明示為建置目標；現場優先看見使用限制 |

不改變正式資料存取權限、API、資料庫、簽署、匯入或正式新增／匯出限制。正式模式即使誤收到合成資料，也不顯示其姓名、紀錄或展示明細。此為額外呈現邊界，不能取代伺服器端授權及不傳送未授權資料的要求。
