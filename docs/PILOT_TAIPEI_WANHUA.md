## 接下來的執行順序與驗收輸入

1. 收集設立許可（含機構代碼、核定服務與容量），由機構指定負責人核對全名與分支。通過後才規劃正式租戶資料；不將 public profile 直接寫入正式資料庫。
2. 取得 **115 年有效特約契約及附件、主管機關現用空白申報模板、去識別化成功申報與退補件／核定回覆各一份**。先在本機完成欄位字典、精確金額、格式解析、不可變快照與逐筆對帳測試。
3. 取得上次評鑑結果／效期及實際受評通知，確認使用 115 日照法定評鑑或其他有契約依據的版本。逐題建立證據對照、適用性與雙人覆核，不提前計分。
4. 將經核准的欄位、代碼、費率與期限提交第 82 頁版本發布流程；不得以此來源索引取代發布。沒有核准版次時，正式匯出與臨床／法定規則繼續拒絕執行。
5. 東京區域正式環境、DPA、七年 WORM、MFA／RLS、正式權限與災復等依 `PRODUCTION_GATES.md` 驗收後，再安排去識別移轉彩排及平行運行。

以上所需資料不包含登入密碼、API secret 或家屬個資。含個資的樣本須去識別，不放入公開 repository、一般測試站或研究工具。
