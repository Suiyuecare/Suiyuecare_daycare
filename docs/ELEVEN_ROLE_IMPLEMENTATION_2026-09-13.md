# 十一類職務分類：本次變更與驗收

日期：2026-09-13。僅本機程式、資料庫 migration 與合成資料驗證；未推送、部署、修改正式角色或開通真實帳號。這是角色分類的一次增量，不代表原 89 頁或完整上線計畫已驗收。

## 使用者可見變更

- 第 81 頁提供依使用者指定順序的 11 種標準分類。清單預設收合，保留多點／單點及主任兼任說明；「有效角色」仍取實際快照，不顯示假的 11 個已開通角色。
- 第 59 頁員工目前角色、指派選單，以及第 83 頁盤點負責角色、主管準備清單同步新職稱。
- 機構主任可另外申請護理／社工角色；選主任不會連帶寫入其他角色，不代表臨床資格或執登已核對。
- 第 81 頁若單點系統角色配到全機構 membership，送審前顯示指定據點原因並拒絕送出。自訂角色不因相同 key 被錯擋；撤銷仍可操作。API／DB 仍是權限來源。
- 761–900px 角色頁只顯示行動卡片，不再同時顯示桌面表格。
- 檢查中發現資料盤點日期的 Node／Chrome 空白格式不同會造成 hydration 錯誤；改用既有固定台北格式工具，保留原時間值。

## 權限與資料不變的界線

標準角色及新主任的六項讀取權限見 [資料庫驗證](ROLE_TAXONOMY_DATABASE_2026-09-13.md)。舊十個 UUID／key 與權限不變，僅標準名稱更新；新增主任不自動指派給任何人。自訂角色、歷史申請名稱、舊稽核與照顧資料不重寫。

本次沒有放寬：正式登入白名單、Google 身分對應、AAL2 高風險操作、財務總覽、主管準備清單／盤點的既有角色限制、家屬同意與維護人員隔離。主任完整工作功能與專業資格查核不能以「分類已建立」取代。

## 驗收標準與證據

| 項目 | 判定方式 |
|---|---|
| 十一類名稱與順序 | 共用 catalog 單元測試，瀏覽器展開後讀出 11 個 dt |
| 實際授權不假造 | 示範快照仍是 4 角色／3 成員；建立與核准按鈕仍唯讀 |
| 名稱與寫入分離 | 系統名稱更新、自訂同 key 名稱保留、歷史申請原名不改、角色 UUID 請求不變 |
| 主任不自動兼任 | UI 送出只含一個角色；DB 精確六項讀取權限，不含護理／社工寫入、用藥或簽署 |
| 單點不變多點 | UI 預檢、DB 請求及實際指派拒絕 NULL branch；跨分支／跨機構 RPC 拒絕 |
| 升級不靜默重派 | 舊不合規指派使 migration 原子中止；合法非空合成會員、臨床與稽核保留 |
| 行動與鍵盤 | 390／820px 無桌面表格重複，1440px 使用表格；Enter 開展分類、焦點保留；各表格區可鍵盤捲動 |
| 日期穩定 | 盤點畫面固定台北 YYYY/MM/DD HH:mm:ss，測試排除 Unicode 空白差異 |

## 本機檢核紀錄

已通過 `pnpm lint`、`pnpm typecheck`、`pnpm build` 及 `git diff --check`。最終 `pnpm test` 為 3,759 項通過、1 項依環境略過（355 個測試檔通過、1 個略過）。SQL 全量結果見資料庫驗證文件；角色專項 51 項及升級 19 項已通過。PGlite 不等於原生 PostgreSQL 並行／正式 OAuth 驗收。

瀏覽器比較：第 59／81／83 頁各 390、820、1440px；第 58 頁 390、1440px。相同合成來源與路由，快照產生時間可不同。24 張圖檔保存在 [前後對照](qa/2026-09-13-roles/compare.html)。修改後寬度檢查無文件橫向溢出；分類 Enter 展開保留焦點；1280px 成員表可取得焦點，以 ArrowRight 捲動且有焦點框。最終獨立瀏覽器工作階段的四頁載入無 runtime error，日期 hydration 錯誤未再出現。表單的實際送審以元件/API/SQL 合成測試驗證，唯讀展示瀏覽器不解除寫入限制。

已知未完成：全站沿用的橘色導覽／麵包屑及舊治理提示有色彩對比問題，axe 仍非零；本次不更動既有 Finance 配色，也不宣稱 WCAG 2.2 AA 已通過。1280px 展開分類後的 axe 原始結果另存 JSON，剩餘 1 類 color-contrast／2 節點問題，以及 1 類漸層色彩需人工確認；捲動區鍵盤錯誤已消失。Next build 原有 preferredRegion deprecated 提示仍在；部署區域未變更。

正式套用前仍須檢查實際單點角色的分支、核准使用人與職務、原生 PostgreSQL 及實際 Google 登入矩陣，並將 DB／前端作為同一版本發布。尚未完成這些證據，不可把本機測試視為正式帳號可用證明。
