# 日照補齊版驗收紀錄（2026-10-12）

## 放行結論

本文件記錄候選程式、隔離測試及東京資料庫作業，不是「全套已正式上線」證明。
正式前台尚未切換到東京；不得以唯讀合成預覽、偽造使用者、測試 JWT 或取消權限限制代替真人作業驗收。
本輪沒有合併主分支、提升正式 Vercel deployment 或將未核准的臨床規則發布為正式版本。
候選程式已提交 [GitHub PR #37](https://github.com/Suiyuecare/Suiyuecare_daycare/pull/37)，GitHub 整合產生唯讀合成 Vercel 預覽；它不是正式業務環境。

## 本輪修正的實際缺陷

- 家屬權限函式存在循環呼叫，已改為獨立且精確的有效同意判定。
- 家屬訊息在等待資料鎖期間撤權後仍可能寫入；現在取得鎖後再次驗證分支、機構及精確收件人同意，含重送回執。
- 品質月報及評鑑覆核／封存有相同的鎖等待撤權缺口，已在全部六個資料鎖之後重驗權限與近期驗證。
- 最後交叉檢查發現收案準備／獨立覆核的冪等回執也有同類缺口，已在兩個資料鎖之後、回執查詢之前重驗有效範圍、近期 AAL2 與獨立主任職務。
- 家屬機構／分支停用未完整納入授權判定，已補齊。
- 僅執行長可進入的舊入口與新員工角色不一致，已對齊；內層欄位、資格、個案與簽署檢查沒有移除。
- 新來源的待收案評估草稿未完整接到個案中心，已以來源及權限白名單連結；正式作業仍拒絕。
- 行動選單關閉後焦點回復時背景仍為 inert；已修正時序。
- 家屬行程與訊息收合按鈕只有 24px 高度；已提升到至少 44px。
- 新外鍵缺索引及非必要公開 SECURITY DEFINER，已補索引並改為 invoker。
- 舊測試混用 UTC 與台北日期、過時角色權限及非原生登入 fixture，已修正測試資料；不是降低正式驗證條件。
- Node 原生測試被 Vitest 誤掃描，已分開執行；備份還原成功證據改為 PostgreSQL 真正停止後才寫入。
- 還原資料庫原有本機 TCP trust 連線，已改為無 TCP 監聽、0700 Unix socket；發布檔案檢查也補上私檔容器、路徑穿越、父層符號連結與不洩漏輸入的錯誤回應。
- 還原啟動逾時可能未停止已啟動的 postmaster；現在即使啟動回傳失敗，也必須檢查自建資料庫，確認停止且 PID 已消失才能清除精確暫存目錄。不確定、停機或清理失敗均不寫成功回執。四輪舊明文還原暫存亦已核對停止後清除，加密備份保留。
- 實際還原再發現 macOS `/var` 展開 `/private/var` 後 socket 名稱過長；已保留 OS 短路徑供啟動，另以 canonical path、inode、UID 及 0700 驗證清理範圍。

## 證據與重跑

驗收結果以最後一次完整執行結果為準。程式檢查、PGlite、native PostgreSQL、瀏覽器合成試用與雲端資料核對分開記錄。

已確認的證據：

- Vitest：529 個檔案、5,859 項測試全過，含實際已授權來源的唯讀差異核對；無跳過。
- Node 隔離工具：110 項全過（壓測工具契約 12、發布前檔案檢查 71、營運鎖後授權契約 4、收案鎖競爭契約 3、備份清理失敗／OS 路徑情境 20）；不代表正式 HTTP 壓測。
- 完整 PGlite 回歸：144／144 套件、6,729 項檢查全過；92 套件使用凍結的舊本機准入 fixture，52 套件不覆寫准入判定。
- 真正 PostgreSQL 17.11：169 個 migration 編譯、10 套件 673 項全過，沒有正式准入判定覆寫。
- 真正 PostgreSQL 並行工作階段：45 組已觀察資料鎖等待的競爭／撤權／重送測試全過；沒有額外業務紀錄或過期回執。新增 14 組包含收案新增／重送期間撤銷 session、分支、Auth session AAL2 或主任職務；主任職務撤銷案例保留管理員權限，以確認拒絕原因不是混同的全帳號停權。
- 本機唯讀合成路由：89／89；最新 390px／1440px 家屬回歸 35 項全過，前批 48 項報告另存，兩批不得相加當成 83 個獨立測項。
- 最新正式程式建置與型別檢查成功；相依套件掃描沒有已知弱點。
- Vercel 實際 dry-run manifest 通過檔案檢查；GitHub 整合僅建立唯讀合成 preview deployment，沒有提升正式 deployment。
- 東京專案即時確認 `ap-northeast-1 / ACTIVE_HEALTHY`，23 筆來源主檔皆為待收案、17 筆核對、跨範圍錯置 0。
- 最後一個 migration 套用後重新備份及隔離還原：353 張資料表、4,321 筆資料，逐表／逐列指紋完全相同；還原耗時 2.15 秒，TCP 監聽停用、Unix socket 目錄為 0700，還原伺服器已停止且精確明文目錄已移除。這不是平台 PITR、Storage 檔案還原或正式 RPO／RTO 證明。
- 原生本機 PostgreSQL 額外驗證兩個清理情境：真實啟動失敗、真實啟動成功後人工模擬呼叫方漏報失敗；均確認停止／清除，未冒稱真實逾時、雲端或正式故障演練。

上述 PGlite 數字不能替代原生權限與並行測試；本機還原速度不能直接作為正式災難復原承諾。

```sh
pnpm lint
pnpm typecheck
pnpm test
pnpm test:local-harnesses
pnpm test:database
pnpm build
pnpm audit --prod --audit-level=moderate
```

`test:database` 有凍結的舊 PGlite 多角色 fixture；那些舊套件僅驗證內層權限，不能單獨證明原生員工准入。新員工、家屬、收案與護理／社工套件不覆寫准入判定；重要條件另外用真正 PostgreSQL 工作階段及鎖競爭測試。

私有來源、還原容器、帳號憑證、瀏覽器截圖與測試輸出位於忽略目錄，不得提交公開 GitHub，也不得送入 Vercel 打包。

| 七年移轉／申報 | 取得帶來源 ID 的七年全量資料、附件清單、年度縣市正式格式與回覆樣本 | 兩次彩排、全筆關鍵欄位及金額核對，重大差異 0，一個完整申報週期平行驗證 |

以上任一必要門檻未通過，都不得以「全部功能已正式可用」對外發布。
