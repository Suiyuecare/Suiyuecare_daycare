# AD8 候選題本草稿：放行邊界

本版本僅供授權員工記錄八題原始回答，不是正式施測、分數、診斷、轉介、照顧決策或簽署紀錄。入口為 `/app/staff/assessments/ad8`，與原有九份可填量表共用受控草稿核心，但不加入正式量表計分與評估進度矩陣。

## 題本依據

- 題本：[臺東縣衛生局《AD-8 極早期失智症篩檢量表》110.04.30 修訂版](https://ttshbltc.ttshb.gov.tw/ttshb/other/%E8%87%BA%E6%9D%B1%E7%B8%A3AD8%E6%A5%B5%E6%97%A9%E6%9C%9F%E5%A4%B1%E6%99%BA%E7%97%87%E7%AF%A9%E6%AA%A2%E9%87%8F%E8%A1%A8.pdf)。八題保留全部概念與例子，供填答的選項固定為「是，有改變」「否，無改變」「不知道」。
- 題本版本：`ad8-taitung-1100430-candidate-v1`。新增版本時不得改寫既有草稿或在原版本下更換題目、答案代碼。
- 「不知道」是有回覆但無法確定；「待答」是尚未取得回覆。官方題本沒有第四個「不適用」選項，因此 API 與資料庫均拒絕該狀態。若未問到或暫不作答，應保留待答。

## 技術與權限

- 讀取需 `clients.read` 與 `questionnaire_cognition.read`；寫入另需 `questionnaire_cognition.manage`。正式資料僅顯示同分支、指派或 `clients.view_all` 範圍內個案；未選個案的名單不夾帶答案。
- 寫入沿用 `public.mutate_questionnaire_assessment` 的單一交易、冪等鍵與附加版本；相同鍵相同內容只回傳原收據，相同鍵不同內容拒絕。
- 儲存狀態固定 `draft`。客戶端、API 與資料庫均無 AD8 計分規則；API／RPC 拒絕 `score`、`classification`、`diagnosis`、`signature` 等欄位。
- 展示模式只使用合成個案，不能呼叫正式資料庫寫入。

## 正式放行前仍需完成

1. 核對題本重製授權文件、使用範圍與法務紀錄，以及題本與原始 PDF 逐字／語意校對。
2. 由護理／社工與醫師依機構流程確認施測對象、家屬／受訪者、適用情境、進一步評估與轉介規則。
3. 另以雙人核准、版本化規則建立正式計分及生效日期；不可把本候選草稿自動轉成正式結果。
4. 在隔離環境驗證資料庫 migration、角色矩陣、真人帳號、跨個案隔離、行動版與輔助科技，才考慮併入正式部署。
