# 今日工作與評估：保留正確個案、班別及草稿

日期：2026-09-28。這是既有 Finance 外框內的下一批現場操作改善，不擴大權限、不改照顧公式或正式簽署門檻。ABCD 選案清單另需一筆只補列「已驗權、明確選取」個案的資料庫 migration；本機完成不等於正式資料庫已套用或前台已部署。

| 現場問題 | 修改方向 | 驗收標準 |
|---|---|---|
| 今日清單只排一個班別，進入日誌後卻可能以「全日」新增 | 從已確認的個案分工帶入班別；同日兩班的班別型工作須明確選班，不猜一班 | 上午／下午日誌連結帶正確班別；待辦只提供仍需處理的班別；整日草稿不得套到已簽班別；出勤是個案＋日期事件，不冒充上午／下午確認 |
| 無分工的主管看見空清單，還要再找工作入口 | 空狀態直接引導到每日分工，展開表單並聚焦標題 | 點擊後分工表單已展開、鍵盤焦點清楚；不把空清單顯示成已完成工作 |
| 從評估入口選了個案，A／B／C／D 新增表單卻可能選到名單第一人 | 只採用通過本頁授權名單核對的所選個案；無有效選案時明示待選；超過前 200 名時僅補列已驗權且明確選取的個案 | 選 B 新增與請求均是 B；無效或無權限網址不能預選 A，未選個案不能送出；第 201 位可用但未授權者不可見；展示及既有審核門檻不變 |
| 裝置草稿刪除跳出瀏覽器原生確認 | 沿用站內確認框與既有 revision 比對，並在列表與確認框顯示同一草稿編號 | 取消／Escape 零刪除；雙擊只刪一次；同日同類別兩筆可辨識；其他分頁更新時舊版不得刪除；明確告知只影響此裝置，不能撤回已送伺服器的紀錄 |
